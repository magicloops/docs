# Magic Loops Glossary

This glossary provides definitions for key terms used in **Magic Loops**. You can switch between **technical** and **non-technical** explanations to better understand each concept.  

---

## **Key Terms**  

### **1. Loop** 🔄  
- **Technical:** A sequence of automated tasks that execute repeatedly until a condition is met.  
- **Non-Technical:** A set of instructions that run over and over to automate a process.  

### **2. Block** 🧩  
- **Technical:** A modular component that performs a specific function within a loop, such as fetching data, processing information, or making API calls.  
- **Non-Technical:** A building block that helps automate different tasks, like grabbing information or sending messages.  

### **3. Variable** 🔢  
- **Technical:** A named storage for data that can change dynamically within a loop, used to store and manipulate information.  
- **Non-Technical:** A placeholder that holds changing values, like a name or number, to use in automation.  

### **4. API Call** 🌐  
- **Technical:** A request sent from Magic Loops to an external service to retrieve or send data.  
- **Non-Technical:** A way for Magic Loops to talk to other websites or apps to get or share information.  

### **5. Fetch** 📡  
- **Technical:** A process of retrieving data from a remote source, often using HTTP requests.  
- **Non-Technical:** A way to grab data from the internet to use in a task.  

### **6. Trigger** ⏳  
- **Technical:** A predefined event that initiates the execution of a loop (e.g., a scheduled time or an API request).  
- **Non-Technical:** Something that starts an automation, like setting an alarm to begin a task.  

### **7. Manual Loop** ✍️  
- **Technical:** A user-defined automation created by typing a natural language prompt, which is then converted into structured blocks by AI.  
- **Non-Technical:** A way to build an automation by describing what you want in simple words.  

### **8. JSON** 📄  
- **Technical:** A lightweight data-interchange format used for structuring information in a readable and parsable way.  
- **Non-Technical:** A way to organize data so that computers can easily understand and share it.  

### **9. Dashboard** 🖥️  
- **Technical:** The main interface where users manage their loops, blocks, and execution logs.  
- **Non-Technical:** The home screen where you create and manage your automations.  

### **10. Authorization Token** 🔑  
- **Technical:** A security credential used to verify a user’s identity and grant access to specific resources or APIs.  
- **Non-Technical:** A digital key that allows you to access secure data or services.
